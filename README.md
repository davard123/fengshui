# Feng Shui App

Local-first Expo Router scaffold for the feng shui MVP.

## Scope

- Disclaimer gate
- Birth year / gender setup
- Optional detailed birth info entry
- Property address entry
- Compass capture
- 10-question housing questionnaire
- Report screen
- History screen

## Notes

- This repository currently contains the AI 1 frontend shell.
- Feng shui scoring and report generation rules are meant to be filled by the AI 2 worker.
- The app is designed to stay local-first and keep the flow short.
